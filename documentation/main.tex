\item \textbf{Foundations of Neural Networks}\\
Introduction to neural network concepts, and core
components such as neurons, layers and parameters.

\item \textbf{Initial Implementations}\\
Manual implementation of single neurons and multi-neuron layers with
emphasis on mathematical foundations.

\item \textbf{Vectorized Computation}\\
Transition to NumPy-based implementations using vectors, matrices,
batching, and efficient matrix operations.

\item \textbf{Multi-Layer Network Construction}\\
Encapsulation of dense layers into reusable classes and structured
handling of training data.

\item \textbf{Activation Functions}\\
Implementation of linear and non-linear activation functions,
including Sigmoid, ReLU, and Softmax.

\item \textbf{Loss Functions and Evaluation}\\
Integration of categorical cross-entropy loss and accuracy metrics
for model evaluation.

\item \textbf{Optimization and Backpropagation}\\
Gradient-based optimization, derivatives, chain rule, and full
backpropagation pipeline.

\item \textbf{Optimizers}\\
Implementation of SGD, learning rate decay, momentum, AdaGrad,
RMSProp, and Adam.

\item \textbf{Regularization Techniques}\\
L1 and L2 regularization, dropout, and validation strategies to
improve generalization.

\item \textbf{Classification and Regression}\\
Support for binary classification and regression tasks with
appropriate loss functions.

\item \textbf{Model Abstraction}\\
Introduction of a unified model object encapsulating layers,
losses, and optimizers.

\item \textbf{Real-World Data Integration}\\
Data loading, preprocessing, shuffling, batching, and training
on real datasets.

\item \textbf{Model Persistence and Inference}\\
Saving and loading model parameters and enabling prediction
on unseen data.

\end{enumerate}
